## ✨ Key Features

- 🌌 **Premium UI/UX**: Ultra-modern dark mode with elegant Glassmorphism effects and soft glowing accents.
- 🎨 **Dynamic Design**: Interactive 3D parallax effects using `react-parallax-tilt` and mesmerizing background particles.
- 📉 **Performance Optimized**: GPU-accelerated scroll snapping and layout transitions for a buttery-smooth feel.
- 📱 **Fully Responsive**: Flawless experience across all screen sizes, from mobile to ultra-wide displays.
- 🖋️ **Typewriter Interaction**: Dynamic landing page intro with custom typewriter effects.
- 🗓️ **GitHub Activity**: Live integration of GitHub contribution graph using `react-github-calendar`.
- 📄 **PDF Resume Viewer**: Seamless integration for viewing and downloading professional resumes.
- 🔍 **SEO Ready**: Semantic HTML5 structure with optimized meta tags and lighting-fast load times.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
- [Node.js](https://nodejs.org/en/) (v16.x or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/vinaykharvi/portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm start
   ```
   *Your browser will automatically open at `http://localhost:3000`*
